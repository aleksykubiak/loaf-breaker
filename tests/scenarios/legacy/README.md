# Legacy scenarios

These scenarios drove LOAF BREAKER's old SEQ page (the pattern's break steps and the kick, snare, hat and clap lanes)
or expected SEQ to open it. SEQ is the BASS's now (ui/bass.c: eight bass lines of two bars), so they can no longer run
as written and are left out of CI. The features they reached through those lanes (X2, X4, TRI, KIL, the kick rolls,
HITS, the crossbreed, VINYL BREAK on the kick) are still in the firmware and still act on the patterns' drums.
